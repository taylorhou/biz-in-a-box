# What This Is Not (Yet)

`biz-in-a-box` is intentionally small. That is a strength.

It is **not yet**:

- A full ERP suite
- A tax engine
- A payroll system
- A full AR/AP subledger product
- A compliance package for every jurisdiction

## Current role

Today, it is a **protocol foundation**: a durable, append-only source of truth that agents and humans can read, write, validate, and audit.

## Why this matters

The fastest path to replacing legacy software is:

1. Standardize the core ledger primitive
2. Run in parallel with legacy systems
3. Reconcile until records match
4. Replace layers incrementally

See `ROADMAP.md` for hardening milestones and replacement path.
